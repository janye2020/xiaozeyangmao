💡 快速更新发布三步法

  1. 在上面输入框粘贴好您的推广口令后，点击 【一键下载 config.js】；
  2. 将下载的文件直接拖入本项目的 assets/ 文件夹，覆盖原来的 assets/config.js；
  3. 在本地终端运行：git add . && git commit -m "update: 更新推广口令" && git push；Cloudflare 就会在几十秒内自动更新上线！
